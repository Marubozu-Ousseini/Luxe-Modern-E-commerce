# IA Redesign — Sitemap & Page Templates

Goal: Simplify flows, surface products quickly, and reduce cognitive load while keeping existing architecture.

Sitemap (top-level):
- Home (Shop discovery + hero + category chips + curated promos)
- Boutique (Product listing with filters)
- PDP (Product Detail Page)
- Cart (drawer + full checkout page)
- Checkout (checkout flow)
- Showroom / Story / Galeries (brand content)
- Account (orders / favorites)

Homepage template
- Compact hero (1-line value prop + primary CTA)
- Category chips under hero
- Featured collections (best-sellers, new, curated)
- Social proof row (testimonials + press)

PDP template
- Left: gallery (image/video) with thumbnails
- Right: category tag, title, price (large), one-line value prop, urgency/stock, trust microcopy, quantity + primary CTA (sticky on scroll)
- Below: accordions (details, materials, shipping), curated cross-sells, verified testimonials

Cart UX
- Keep drawer for quick edits, show clear savings and single primary CTA to checkout
- Move coupon to checkout page and allow quick paste on drawer with hint only

Navigation
- Desktop: keep top nav but prune low-value links
- Mobile: bottom nav with: Shop, Search, Favorites, Cart, Account

Notes
- No architecture changes required; only component placement and copy.
